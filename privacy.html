1. Nessuna raccolta o trasmissione di dati personali

Acta è un'applicazione desktop progettata per funzionare interamente in locale sul dispositivo dell'utente. Acta non raccoglie, non trasmette, non vende e non condivide alcun dato personale, screenshot, testo, documento o telemetria con lo sviluppatore o con terze parti.

L'applicazione non richiede account o registrazione, non include SDK pubblicitari o di analisi e non effettua connessioni verso server esterni.

2. Dati creati e conservati esclusivamente sul tuo dispositivo

  • Registrazioni ed esportazioni: gli screenshot, le bozze dell'editor e i file esportati (PDF, Word .docx, HTML e Markdown .zip) vengono salvati solo nella cartella archivio locale sul tuo PC (predefinita: ~/Acta_SOP, oppure altra cartella scelta da te).
  • Preferenze e log diagnostici locali: le impostazioni dell'interfaccia (lingua, tema, cartella archivio) e un log diagnostico tecnico a rotazione (logs\acta.log, che registra solo errori tecnici senza screenshot, testi utente o password) sono salvati in %LOCALAPPDATA%\Acta.
  • Editor locale Acta Studio: per modificare e salvare le bozze nel browser, Acta avvia un server HTTP locale vincolato al solo indirizzo di loopback 127.0.0.1 e protetto da un token casuale di sessione; nessun dato lascia il computer.

3. Come vengono usate le funzionalità di sistema

  • Acquisizione schermo e Accessibilità (UI Automation): solo durante una sessione di registrazione avviata esplicitamente dall'utente (segnalata dalla barra flottante), Acta acquisisce gli screenshot dello schermo attivo sui clic oppure su comando manuale dell'utente (pulsante fotocamera o Alt+Shift+C) e interroga in locale Windows UI Automation per leggere, quando disponibile, l'etichetta del controllo cliccato e preparare la bozza del passo.
  • Nessuna registrazione del testo digitato: Acta non registra mai i caratteri alfanumerici digitati sulla tastiera né le password; rileva soltanto le interazioni del mouse e le scorciatoie comando (come Ctrl+C o Invio).
  • Controllo privacy locale (OCR su dispositivo): solo quando l'utente avvia manualmente Controlla privacy in Acta Studio, Acta analizza in locale testi e immagini tramite il motore OCR integrato di Windows (Windows.Media.Ocr) per proporre riquadri rivedibili su possibili dati sensibili (email, IBAN, codici fiscali, partite IVA, carte, password). Al salvataggio del file esportato, le aree oscurate subiscono una riduzione irreversibile dei pixel, così il contenuto coperto non resta recuperabile nell'output.
Responsabilità di revisione: gli screenshot riflettono ciò che è visibile sullo schermo durante la registrazione e il controllo privacy automatico è uno strumento di supporto. Prima di condividere un documento esportato, verifica sempre che tutti i dati riservati siano oscurati come desideri.

4. Controllo, conservazione e cancellazione dei dati

Mantieni il controllo completo su tutti i file generati da Acta. Puoi eliminare singole registrazioni da Acta Home o rimuovere la cartella archivio da Esplora File in qualsiasi momento. La disinstallazione dell'app da Impostazioni di Windows → App rimuove automaticamente le preferenze e i log diagnostici salvati nel profilo applicativo (%LOCALAPPDATA%\Acta).

5. Servizi di terze parti e Microsoft Store

Acta non si collega a servizi cloud di terze parti. Download, aggiornamenti ed eventuale diagnostica di piattaforma gestiti dal Microsoft Store sono regolati dall'Informativa sulla privacy di Microsoft.

6. Modifiche all'informativa e contatti

Eventuali aggiornamenti futuri a questa informativa saranno pubblicati con la nuova data sia dentro l'applicazione (sezione Privacy) sia su questa pagina collegata alla scheda Microsoft Store. Per domande, segnalazioni o richieste relative alla privacy puoi contattare direttamente lo sviluppatore, Nicola Inzerillo, all'indirizzo inzerillo.nicola@gmail.com.

1. No Collection or Transmission of Personal Data

Acta is a desktop application designed to operate entirely locally on your device. Acta does not collect, transmit, sell, or share any personal information, screenshots, text, exported documents, or usage telemetry with the developer or any third party.

The application requires no account or sign-in, contains no advertising or analytics SDKs, and makes no outbound internet connections.

2. Data Stored Exclusively on Your Device

  • Recordings and exports: captured screenshots, step drafts, and exported files (PDF, Word .docx, HTML, and Markdown .zip) are stored solely in your local archive folder (default: ~/Acta_SOP, or another folder you select).
  • Local preferences and diagnostic logs: UI settings (language, theme, archive folder) and a local rotating error log (logs\acta.log, recording technical errors only, never screenshots, user text, or passwords) are stored under %LOCALAPPDATA%\Acta.
  • Local Acta Studio editor: to edit drafts in your browser, Acta runs a local HTTP server bound strictly to loopback (127.0.0.1) and protected by a random per-session token; no traffic leaves your computer.

3. How System Capabilities Are Used

  • Screen capture and Accessibility (UI Automation): only while a user-initiated recording session is active (indicated by the floating toolbar), Acta captures screenshots of the active display on clicks or when manually triggered by the user (camera button or Alt+Shift+C), and queries Windows UI Automation locally to read accessible control labels where available so step instructions can be drafted automatically.
  • No free-text keystroke recording: Acta never records typed text or passwords; it captures only mouse interactions and command shortcuts (such as Ctrl+C or Enter).
  • On-device Privacy Check (local OCR): only when you manually run Privacy check in Acta Studio, Acta scans drafts and screenshots locally via the native Windows OCR engine (Windows.Media.Ocr) to propose reviewable redaction boxes for potentially sensitive data (emails, IBANs, tax IDs, payment cards, labeled secrets). Upon export, redacted areas undergo irreversible pixel downsampling so covered content cannot be recovered from the output file.
User review notice: captured screenshots contain whatever is visible on screen during recording, and automated sensitive-data detection is provided as an assistive check. Always review exported documents before sharing them.

4. Data Control, Retention, and Deletion

You retain full control over all files created with Acta. You can delete individual recordings in Acta Home or remove the archive folder in File Explorer at any time. Uninstalling the app via Windows Settings → Apps automatically removes local preferences and diagnostic logs stored under the application data folder (%LOCALAPPDATA%\Acta).

5. Third-Party Services and Microsoft Store

Acta does not connect to external cloud services. Download, updates, and platform diagnostics handled by the Microsoft Store are governed by the Microsoft Privacy Statement.

6. Policy Updates and Contact

If this Privacy Policy is updated in the future, the revised version and effective date will be published both inside the application (Privacy) and on this page linked from the Microsoft Store listing. For privacy questions or support requests, contact the developer, Nicola Inzerillo, at inzerillo.nicola@gmail.com.
